如何取得雲端下載連結？

Google 雲端硬碟檔案分享 3 步驟：

  1. 在 Google 雲端硬碟中，對檔案點右鍵 ➜ 點選「共用」➜「共用」。
  2. 將「一般存取權」改為「知道連結的任何人」，角色設為「檢視者」。
  3. 點擊「複製連結」後貼至上方欄位即可！

如何免費將業務面板發布至 GitHub Pages（3分鐘圖解）

什麼是 GitHub Pages？

GitHub 提供的免費靜態網站託管服務，支援 HTTPS 安全加密、24小時全年不中斷、全體分隊同仁在任何地方都能用手機或電腦直接開啟！

步驟 1：在 GitHub 建立一個公開倉庫 (Repository)

1. 前往 github.com 登入或免費註冊帳號。

2. 點擊右上角的 「+」➜「New repository」。

3. Repository name 輸入例如：shuishang-portal。

4. 勾選 Public (公開)，其他維持預設，點擊「Create repository」。

步驟 2：直接在網頁上傳專案檔案

1. 在新建立的倉庫頁面中，點擊 「uploading an existing file」（上傳現有檔案）。

2. 將本專案資料夾內的檔案直接拖曳進瀏覽器：

  • index.html (最關鍵主頁面)
  • data.json (初始業務與表單資料)
  • README.md (說明文件)

3. 點擊下方的綠色按鈕 「Commit changes」 完成儲存。

步驟 3：一鍵開啟 GitHub Pages 網站

1. 點擊倉庫頂部的 「Settings」（設定標籤）。

2. 在左側選單點選 「Pages」。

3. 在「Build and deployment」下的 Branch，將 None 切換為 main，目錄保持 / (root)。

4. 點擊 「Save」。

🎉 等待約 1 分鐘，重新整理頁面，頂部就會顯示專屬的網址：
https://您的帳號.github.io/shuishang-portal/

更快速的方法：Netlify Drop (10秒免註冊部署)

若暫不想建立 GitHub 帳號，可前往 app.netlify.com/drop，直接把包含 index.html 與 data.json 的資料夾整包拖曳進去，10 秒內即可獲得一組免費的 HTTPS 專屬永久網址！
